# Laraque Capital Group Website

A single page website for Laraque Capital Group, built in one self contained file: `index.html`. All styles, scripts, photos, floor plans, and logos are embedded inside it, so the site runs with no other files.

## Files

- `README.md` This guide.
- `index.html` The complete website.

## How To Publish

- Wix or Squarespace: add an HTML embed or custom code block and paste the full contents of `index.html`.
- GoDaddy, Hostinger, or Bluehost: upload `index.html` to the site's root folder (often `public_html`).
- Netlify or Vercel: drag the `laraque-site` folder into the dashboard to deploy it.

## How To Make Edits

- Open `index.html` in any text editor.
- Search for the text to change, such as a heading or phone number.
- Replace it, save the file, and upload it again.
